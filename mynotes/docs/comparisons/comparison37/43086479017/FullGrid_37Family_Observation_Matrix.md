## Interpretation boundary and next comparisons

- This cohort used fresh, short emulator sessions across shards. A successful matrix run is not a 600-minute soak, a single uninterrupted session, or proof of emulator stability. The separate traced guest-loss run did not reproduce the loss; its root cause remains unknown.
- Screenshot review, task-route equivalence, meaningful outcomes, saved/reopened content, OCR/audio accuracy and speed across varied Indian-language material, Office/PDF fidelity on complex files, accessibility, animation, efficiency, novice comprehension and human/physical testing are not established by these counts.
- No feature absence or comparative winner is inferred from an unavailable route, API shortcut, blocked probe, capture-owner flag, installation size, status count or green CI job. Preserve individual evidence and run cohorts separately.
- Production fixes remain parked until the comparison phase is complete. Root QA passed 1,149 tests before this report publication; that is repository QA, not acceptance of the product tasks.
