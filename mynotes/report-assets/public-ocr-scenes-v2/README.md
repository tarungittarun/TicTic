# Public varied-scene OCR evaluation v2

Three original public iOS screenshots containing two nature photos. Five frozen inputs: two complete photo/dialog screenshots, one selected-row crop, two no-text nature-photo crops. Not five independent source photos, positive street-sign OCR, private screenshots or untouched heldout data. References manually transcribed from original visible pixels before inference. Crop coordinates are frozen, not engine-selected.

Original bytes are Git-blob- and SHA256-bound in manifest.json. Repository Apache2 license retained verbatim. No private/user pixels. These assets are never production-packaged. Recognition references do not enter inference or production output selection. Preserve misses, status-icon inventions, input hashes and latency separately; whole-image CER alone cannot qualify symbol/script accuracy.
