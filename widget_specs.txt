Weather is an optional per-widget add-on in Studio for supported clock designs (Clock, Date, Alarm, Analog, Skyline, Coral, Quiet, Aurora, Prism and Halo). When enabled, the widget uses a user-entered city and a selected 30/60/120-minute refresh interval. Android can defer network-constrained jobs; these are requested intervals, not guaranteed update times. No location permission is requested. The app makes no weather request before the user enables weather for that widget. Current conditions are cached locally and stale data is not replaced with a fabricated forecast.

Wallpaper matching is also opt-in per widget. It reads only Android `WallpaperColors` metadata; it does not read wallpaper image files, request a picker, capture the screen or prompt for storage access. If metadata is unavailable, the widget uses its sample palette.

Weather source/licensing gate: Open-Meteo free API and its geocoding endpoint are for non-commercial use. Attribution is shown in the widget and Studio; forecast data is CC BY 4.0. A commercial app, subscription, ad-supported distribution or other commercial integration must use a suitable paid plan before release. See https://open-meteo.com/en/terms and https://open-meteo.com/en/licence.

The four signature layouts (Prism, Flip, Console and Halo) use static layered Android drawables rather than continuous 3D animation or blurred screen captures. AppWidget launchers and lock-screen surfaces vary by Android/OEM; no universal lock-screen placement is promised.
